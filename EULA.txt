6. DATA COLLECTION, PRIVACY AND CONNECTED SERVICES

   a. Station heartbeat. Unless you turn it off in Settings (the telemetry option) the software
      sends a short status message about every five minutes to Augeas's fleet service. It
      contains: a random station identifier, the station name, the computer's host name and
      operating-system version, the software version, which instruments are connected and their
      basic state (for example idle, running or fault), licence status and licence identifier,
      time zone, the site label if you set one, and a summary health score. It does not contain
      run data, recipes, results, user names or passwords. Augeas and IonField use it to support
      and maintain your Equipment, detect faults, manage licences and improve the software.

   b. Update checks. Update checks (section 5) request a signed manifest from Augeas's public
      update channel, which is hosted by GitHub, Inc. These requests reveal your IP address to
      that host, as any download does.

   c. IFS AI. If you choose to use IFS AI, the question you type and the station information
      needed to answer it (for example current readings, recent events and configuration) are sent
      to the AI provider you configure - for example Anthropic, OpenAI, or a model on your own
      network - using your own account and key where you supply one. That provider's own terms
      and privacy policy govern that processing. AI answers can be wrong; check them before you act
      on them, and never use them to override a safety warning.

   d. Local data. Run logs, Data Log files, Insight history, protocols, recipes, accounts and
      settings are stored on your own computer, in your user profile. You are responsible for
      backing them up, and for any personal data you choose to put in them.

   e. Licences. Licence files are verified on your computer, without a network connection. If
      you activate or release a licence key, the key, the station identifier and the station name
      are sent to Augeas so that it can issue the licence and count the seats in use.
